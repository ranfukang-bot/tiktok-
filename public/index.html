每日额度与发布时段

填 0 表示不限。按下面的时区算"一天"，发够就停，第二天当地0点自动刷新。
做哪个地区就选哪个地区的时区，额度和发布时段都按当地时间算。
额度是按当地0点刷新的，但"刚过0点有额度"不代表这时候该发——文件夹里堆着视频的话， 不开这个会变成凌晨几点连发好几条，没有真人会这样发。开着的话，时段之外攒着的额度不会丢，等时段开始接着发。

发布完之后做什么

一个开着的窗口要占一千多MB内存，账号多了电脑会很吃力。开着这项的话， 只在确认发布成功那一刻才关，下一条到点了再重新开。 出错或者发布结果不确定的时候会一直留着窗口——那种情况本来就要你打开这个号 看一眼（内容列表到底发出去没有、是不是哪个检查开关被关了），关掉你就没得看了。 关窗口不影响登录状态和指纹，那些是指纹浏览器自己存着的，重开还是原样。
开着的话，文件夹本身就是"待发布清单"：里面还有视频=没发完，空了就该加新的，不用再对照进度列表。 只在真正确认发布成功那一刻才移（不确定/失败/暂停都不会动）——是移到回收站，不是永久删除，误删还能捞回来。

出问题时通知我

TikTok Studio 通用识别

自动按页面结构识别上传、商品、AI声明、立即发布和检查结果，无需选择国家或填写界面翻译。 只有音乐版权和内容检查两项都明确通过才发布；红色、检查未完成、检查关闭或未知结构都会停止。
页面改版或账号缺少商品橱窗等功能时会报错暂停，不会猜按钮、不会跳过检查。
